# R&AV LINE FOLLOWER ROBOT

> A High-Performance, Memory-Enabled, Path-Optimizing Autonomous Robotics Platform

---

# Overview

This repository documents my three-year engineering journey in designing and developing advanced Line Following Robots (LFRs), beginning from a simple beginner-level robot and evolving into a fully modular, memory-enabled, shortest-path-optimizing autonomous navigation platform.

The project progressively expanded across multiple engineering domains including:

- Embedded Systems
- PID Control Systems
- Autonomous Navigation
- Sensor Engineering
- PCB Design
- Runtime Configurable Interfaces
- EEPROM-Based Memory Systems
- High-Speed Robotics
- Custom Sensor Array Development

---

# Development Timeline

### YEAR 1 — Foundations of Reactive Robotics

- Basic IF-ELSE line following
- Sensor expansion experiments
- Mechanical calibration systems
- Drive system optimization

### YEAR 2 — Precision Control & Embedded Systems

- PID-based motion control
- Custom PCB development
- High-speed navigation
- Hybrid sensor architectures
- Competition-oriented optimization

### YEAR 3 — Intelligent Autonomous Robotics

- Teensy 4.1 migration
- Runtime configurable OLED interface
- EEPROM-based profile storage
- Shortest path optimization
- Fully custom sensor array development
- Autonomous path memory systems
